# The Road Read — Tesla and Waymo safety claims

A self-contained, responsive digital article for CMPE 294. It uses plain HTML, CSS and JavaScript, so no build step or paid hosting is required.

## Preview locally

Open `index.html` in a browser. The site uses relative asset paths and also works under a GitHub Pages project URL.

## Publish at `https://Aryannn97.github.io/GWAR-Tesla-Waymo-Safety-Claims/`

1. On GitHub, sign in to the **Aryannn97** account and create a **public** repository named **GWAR-mytopic**. Its name must match the path in the desired URL.
2. Download and extract the `GWAR-mytopic.zip` package. Upload its extracted contents (`index.html`, `style.css`, `app.js`, and `.nojekyll`) to the **root** of the repository on the `main` branch. Do not upload the ZIP as a single file or put the contents inside another folder. Commit the upload.
3. Open the repository’s **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, set **Branch: main** and **Folder: /(root)**, then click **Save**.
4. Once GitHub shows the published site, open `https://Aryannn97.github.io/GWAR-Tesla-Waymo-Safety-Claims/`. New commits to those files update the page.

The article’s sources are linked in its Sources & methods section. Its comparison illustration and charts are original CSS/HTML graphics.
